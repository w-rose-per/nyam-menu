# 🍓 [냠냠 퀘스트] 디저트테이블냠냠&과일 마곡점 — 모바일 도트 메뉴 선정 페이지

**디저트테이블냠냠&과일 마곡점**([배달의민족 매장 바로가기](https://s.baemin.com/bK000vefFFRgd)) 단체 주문 시, 스마트폰(모바일)에서 **8비트 도트 RPG 상점 퀘스트** 형식으로 **이름 + 음료 1개(HOT/ICE) + 디저트 1·2순위**를 선택하는 GitHub Pages 웹앱입니다.

---

## ✨ 핵심 기능

1. **최초 이름 입력 필수 팝업**
   - 페이지 접속 시 이름 입력 팝업창이 먼저 열리며, 주문자 이름을 입력해야 메뉴 선택 단계로 진입할 수 있습니다.
   - 팝업과 상단 배너 어디서든 **[배달의민족 앱에서 매장·메뉴 사진 보기](https://s.baemin.com/bK000vefFFRgd)** 로 바로 이동할 수 있습니다.
2. **실제 배민 음료 메뉴 100% 반영 (`drinks_photo` 기준 7개 카테고리 66종)**
   - `냠냠 커피(12)` · `1리터 대용량(6)` · `냠냠 라떼(12)` · `냠냠 스무디(10)` · `냠냠 에이드(11)` · `냠냠 차(10)` · `생과일 주스(5)`
   - 매장 제공 기준(`ICE: PET(캔)` / `HOT: 종이컵` / `오직 아이스만 가능`)을 정확히 반영했습니다.
3. **디저트 1순위 & 2순위 (품절 대비 · 중복 선택 원천 차단)**
   - 6대 분류(`과일 모찌` · `그릭요거트과일모찌` · `컵과일` · `휘낭시에` · `주관식 칸` · `선택안함`) 클릭 시 상세 메뉴가 펼쳐집니다.
   - **1순위에서 선택한 메뉴는 2순위 단계에서 `🔒 1순위 선택됨`으로 자동 잠금**되어 반드시 서로 다른 메뉴를 고르도록 가이드합니다 (2순위 도트 가챠에서도 1순위 메뉴 자동 제외).
4. **모바일 퍼스트(Mobile-First) UX**
   - iOS Safari / 카카오톡 인앱 브라우저 자동 확대 방지(`16px` 입력폼), 가로 스와이프 탭, **하단 고정 엄지 액션 바(`이전` / `다음 단계`)**, 모바일 카드형 실시간 현황판을 적용했습니다.
5. **Google 스프레드시트 실시간 연동 & 배민 합산표 원클릭 복사**
   - `주문내역` 시트와 `메뉴별집계` 시트에 **음료 합계 + 디저트 1순위 합계 + 품절 시 개인별 2순위 대체표**가 실시간 기록됩니다.

## 🚀 Google 스프레드시트 연동 방법 (3분 완성)

1. 새 구글 스프레드시트([https://sheets.new](https://sheets.new)) 생성 → **[확장 프로그램] > [Apps Script]** 클릭
2. [`google-apps-script.gs`](./google-apps-script.gs) 파일 내용(또는 웹페이지 우측 상단 **`[⚙️ 시트연동]`** 모달의 코드 복사 버튼)을 붙여넣고 저장
3. **[배포] > [새 배포]** → 유형: **`웹 앱`**, 실행 주체: **`나 (Me)`**, 액세스 권한: **`모든 사용자 (Anyone)`** 선택 후 배포
4. 발급된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 [`config.js`](./config.js)의 `GOOGLE_SCRIPT_URL`에 넣고 푸시하거나, 웹페이지 **`[⚙️ 시트연동]`** 창에서 **`[🔗 팀원 배포용 자동연동 링크 복사]`** 를 눌러 공유하세요.

> **개인정보 보호 안내**: 로컬의 `menu_photo/` 및 `drinks_photo/` 폴더는 [`.gitignore`](./.gitignore)를 통해 공개 Git 저장소 업로드에서 제외되어 있습니다.

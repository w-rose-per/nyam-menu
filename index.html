⚙️ Google 스프레드시트 실시간 연동

팀원들이 모바일에서 선택했을 때 한 시트에 실시간 자동 집계되도록 Google Apps Script 웹 앱 URL을 연결합니다.

2️⃣ 3분 시트 연동 가이드
  1. 새 구글 시트(sheets.new) → [확장 프로그램] > [Apps Script]
  2. 위 [📜 Apps Script 복사] 코드 붙여넣기 후 저장
  3. [배포] > [새 배포] → 유형: 웹 앱, 실행: 나(Me), 액세스: 모든 사용자(Anyone) 배포
  4. 발급된 .../exec URL을 위 칸에 넣고 [🔗 자동연동 링크 복사] 또는 config.js에 입력!
